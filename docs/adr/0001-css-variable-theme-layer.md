# Themes are CSS variable overrides, not rule rewrites

The Modern/Classic UI toggle is implemented as a single `[data-ui="modern"]` CSS layer. CSS variables are the primary mechanism: the layer redefines the palette/affordance custom properties, and the Classic theme is the `:root` defaults — their values are preserved verbatim, pixel-identical to pre-theme releases. Modern redefines the variables it wants to change (`--bg`, `--surface`, `--surface2`, `--border`, `--accent*`, `--text`, `--text-muted`, `--radius`, the hover/`--accent-gradient*` values) and intentionally inherits the remaining Classic values it does not override (e.g. `--warning`, `--on-accent` stay `#fbbf24` / `#fff` from each page's `:root`). The layer is scoped, so Classic can never pick up Modern values.

Separately, the layer carries one scoped structural override: `[data-ui="modern"] .header` (chunks.html sticky header) replaces the Classic `backdrop-filter` blur with a solid `rgba` fill and `backdrop-filter: none`. This is a rule rewrite, not a variable swap — its rendering implication is that the header loses the blurred-glass effect but gains a cheaper paint: no blur composite pass on scroll. It is the only structural override; everything else in the layer is variable-only.

Note: introducing the variable layer required extracting a few hard-coded colors in each page's `:root` into variables (`--accent-rgb`, `--btn-primary-hover`, `--on-accent`, `--accent-gradient*`). The `:root` blocks were rewritten with unchanged values; only the definitions moved into variables, so Classic renders identically to the pre-theme CSS — with one documented exception: `--text-muted` was bumped from `#64748b` (slate-500) to `#94a3b8` (slate-400) because the pre-theme value fails WCAG AA on Classic surfaces (4.02:1 / 3.80:1 / 3.48:1 on `--bg` / `--surface` / `--surface2` respectively). The bumped value clears AA on all three surfaces with margin.

We rejected the previous approach of an additive override layer that restyled rules directly: it bled into the old theme, and the frosted-glass look it enabled (`backdrop-filter` on many surfaces) caused scroll lag on low-end hardware. Variable-based theming keeps render cost near zero — swapping a variable changes paint only, and the single structural override actively removes the one remaining composite pass.
